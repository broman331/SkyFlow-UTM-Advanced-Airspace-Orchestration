# UTM System Build Workflow

This workflow tracks the initialization and implementation of the UAS Traffic Management (UTM) system.

1. Ensure prerequisites (Node.js, Docker, etc.) are installed.
2. Initialize Backend project (Express + TypeScript)
3. Initialize Frontend project (React + Vite + Mapbox GL)
4. Set up database context (PostgreSQL/PostGIS for GeoJSON)
5. Implement microservices focusing initially on the Geofencing Service
